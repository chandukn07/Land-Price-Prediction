How the prediction works

Three simple steps take your property information and turn it into a machine learning price estimate.

01

Enter Property Details

Select the region, land type, road access, utilities, area and other characteristics.

02

Machine Learning

Your property information is sent to the trained Random Forest model through the Flask API.

03

Get Your Estimate

The model returns an estimated total land price and estimated price per square foot.

Technology

Powered by Machine Learning

A Python-based machine learning system connects the trained model with a modern web interface.

🌲

Random Forest

A Random Forest regression model is trained using property characteristics such as region, land type, road access, utilities, area, distance, infrastructure and development potential.

🐍

Python + Flask

Python handles the machine learning model while Flask provides the prediction API used by the website.
